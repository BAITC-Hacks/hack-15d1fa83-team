## Энергетика-прогнозирование выработки ВЭС
### О проекте
Мы разрабатываем систему **Agentic AI**, которая прогнозирует выработку ветроэлектростанции на следующие **24–48 часов**.
Система использует исторические данные ВЭС и прогноз погоды.
### Данные
Исторические данные:
* март 2023 - январь 2026;
* скорость ветра;
* температура;
* активная мощность;
* время измерения.

Тестовый период:
**1-28-февраля 2026 года.**
### Как работает
```text
Погода
  ↓
Обработка данных
  ↓
AI Agent
  ↓
ML-модель
  ↓
Прогноз на 24–48 часов
  ↓
Проверка результата

```

### Что делает AI Agent

Агент автоматически:

1. Получает прогноз погоды.
2. Обрабатывает данные.
3. Запускает модель.
4. Получает прогноз выработки.
5. Анализирует результат.
6. Повторяет прогноз при обновлении данных.
