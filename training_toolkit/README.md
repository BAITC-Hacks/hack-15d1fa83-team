This toolkit is separate from serving. Shared feature code remains in `src/windpower`; low-level scripts stay compatible with existing launchers. / Этот инструментарий отделён от сервиса. Общий код признаков остаётся в `src/windpower`; прежние низкоуровневые скрипты совместимы со старыми запускателями.
